# LEVEL — Frontend

Frontend inicial de LEVEL, tienda digital de videojuegos.

## Tecnologías actuales

- React 19
- TypeScript
- Vite
- Tailwind CSS 4

> Esta es la base visual recuperada del archivo de Figma Make. React debe ser confirmado con el docente antes de considerarlo tecnología aprobada para la entrega.

## Requisitos

- Node.js compatible con Vite 8
- npm o pnpm

## Instalación

```bash
npm install
npm run dev
```

Vite mostrará la dirección local para abrir la aplicación en el navegador.

## Compilar

```bash
npm run build
```

## Estado del proyecto

La versión actual contiene las vistas visuales de inicio de sesión, registro, catálogo, detalle de videojuego y perfil/biblioteca. La navegación y los formularios son demostrativos; todavía no existe backend ni conexión con una base de datos.
